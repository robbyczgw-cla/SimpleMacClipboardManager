# DropForge Roadmap

## Near term

- batch Shop Image execution with a concurrency limit
- native Electron file drag-out
- adjustable resize dimensions and quality
- delete and pin individual outputs
- storage usage display and configurable retention
- workspace naming and switching

## Later

- custom linear image recipes
- generic file rename-copy actions
- PDF merge and page extraction
- QR-code generation
- archive creation
- audio conversion and metadata inspection
- Finder extension
- watch folders
- macOS Shortcuts integration
- plugin SDK
- move into a dedicated DropForge repository with notarized releases
