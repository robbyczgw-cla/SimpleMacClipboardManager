# Launch Checklist

- [ ] Product name and domain selected after naming/legal review.
- [ ] Privacy, Terms, refund and support pages published.
- [ ] Merchant of Record account approved and checkout tested in EUR.
- [ ] Founder and standard one-time products configured.
- [ ] Signed/notarized arm64 and x64 artifacts smoke-tested on clean Macs.
- [ ] Checksums and release notes published.
- [ ] Purchase delivery tested from checkout through first launch.
- [ ] Manual download fallback documented.
- [ ] No clipboard contents, API keys or payment secrets in source or logs.
- [ ] Support workflow asks for app version/order ID before any diagnostic data.
- [ ] Landing-page screenshots show real Saved/Collections and Privacy states.
- [ ] Launch release remains draft until the owner completes the manual smoke
      test and approves publication.
