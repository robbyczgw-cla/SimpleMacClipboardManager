1. **See it, recognize it, reuse it.** Text, links, colors, images and files
   stay visually identifiable instead of becoming an unreadable list.
2. **Recent when temporary. Saved when important.** Saved items are protected
   from Recent retention and can be organized into Collections.
3. **Private by default.** Clipboard data stays on the Mac. No account, cloud
   sync or clipboard telemetry is needed.

## FAQ

**Does [PRODUCT_NAME] upload clipboard contents?** No. Clipboard data is stored
locally by the app. Optional favicon requests and explicit link opening are
separate documented network actions.

**Do I need an account?** No account is required inside the app.

**Does it work with images?** Yes. Images have visual previews and managed
local files; export/import behavior must be verified for each launch build.

**Why is there a paid build if the source is MIT?** The purchase supports
signed/notarized distribution, curated releases, updates and support. It does
not retroactively revoke the existing open-source license.

**Does Direct Paste need permission?** Only when enabled. Copy-only mode and
the global hotkey do not require Accessibility.
